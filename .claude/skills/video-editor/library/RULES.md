# Rules (learned) — read before every video, rewrite via job 6

Concrete, testable rules that override defaults. Each cites the note that created it.

- R1 — One idea = one graphic, held long enough to read. Never one graphic per sentence.
  _(origin: source system — audience comments said per-sentence graphics were too much)_
- R2 — Max 4 concurrent renders. _(origin: source system — 9 parallel renders crashed the machine)_
- R3 — Drafts render at `--quality draft`; delivery quality only after full-cut approval.
